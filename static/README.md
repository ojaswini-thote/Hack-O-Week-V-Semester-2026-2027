# Task Management System

A simple Task Management System built using Flask and SQLite. The application allows users to create, view, update, and delete tasks through a clean web interface.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Features

- Add a task
- View all tasks
- Edit a task
- Delete a task

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
